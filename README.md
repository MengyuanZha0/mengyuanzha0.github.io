# mengyuanzha0.github.io

Academic homepage of Mengyuan Zhao (KTH), built with the [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme.

- Bio: `_pages/about.md`
- Publications: `_bibliography/papers.bib` (`selected={true}` shows a paper under "Selected"; `journal={Preprint}` lists it under preprints)
- Site settings and social links: `_config.yml`

Local preview:

```bash
bundle install   # only needed once
bundle exec jekyll serve
```
